# Code of Conduct

## Our standard

Be respectful and constructive. Assume good faith; critique code, not people. Harassment, personal attacks, publishing others' private information without consent, or sustained disruption are not tolerated in this project's spaces (issues, PRs, chats, events).

## Scope

Applies to the project repository and any official project communication channels.

## Enforcement

Report unacceptable behavior to the maintainers via a private message to @dantoniomarte or through GitHub's report mechanisms. Maintainers will review, respond with an initial decision within 7 days, and may remove, edit, or reject contributions that violate this policy. Repeated or severe violations result in a permanent ban.

This project follows the spirit of the Contributor Covenant (v2.1). Where this document is silent, the Contributor Covenant's interpretation guides decisions.
